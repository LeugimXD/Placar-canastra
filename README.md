# Placar da Canastra

Marcador de pontos da nossa canastra para dois jogadores, feito para usar no celular durante a partida.

- Cada rodada: quem bateu (+100), pontos da mesa e pontos das cartas (já somados com o que ficou na mão do adversário).
- Placar acumulado, histórico, corrigir e desfazer rodadas.
- Aviso de abertura obrigatória (150) a partir de 2.000 e vencedor ao chegar a 4.000.
- Salva automaticamente no aparelho e funciona sem internet. Não precisa de conta.

Para instalar no iPhone: abra o endereço no Safari → Compartilhar → Adicionar à Tela de Início.

Testes dos cálculos: `npm test`.
